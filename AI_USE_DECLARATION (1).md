- 394 automated tests pass (`python -m pytest -q`), including values checked against hand calculations:
  Bayes posterior 0.708 after one alert, 0.070 after no alert, 0.932 after two alerts; first Bellman update

- A\* compared with BFS on 300 random grids (same optimal cost, valid paths, never more nodes expanded);
  Manhattan heuristic checked to be admissible on 50 random grids.
- Monte Carlo evaluation with a fixed seed (20,000 episodes per setting) comparing the agent with four baseline policies.
